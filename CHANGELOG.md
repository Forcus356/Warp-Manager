# 0.4.1

- Исправлена граница окна скорости: последний запрос без новых байтов после
  истечения таймера больше не отбрасывает данные, успешно переданные раньше.
- Пустая вся проба, ранний таймаут, HTTP-ошибка и HTML по-прежнему не принимаются.
- Добавлены регрессионные тесты; всего 97 тестов.
- Обнаруженная смена IP или явный отказ сразу исключают выход из новых
  соединений до окончания долгой проверки; модельный кэш сбрасывается.

# 0.4.0

- Целевая скорость VPS в Гбит/с для независимых режимов Gemini и YouTube.
- Поэтапное выделение до 128 слотов, Docker profiles для спящих подключений.
- Индивидуальные замеры и общий одновременный замер с проверкой IP/здоровья.
- Горячий резерв в треть рабочего пула, немедленное повышение и пополнение.
- Взвешенная балансировка новых TCP-соединений только по рабочим выходам.
- Предел числа слотов, проверка RAM/диска и пауза при насыщении общего канала.
- Отмена старого общего замера при смене состава и сохранение выделений при рестарте.
- Восстановление остановленного контейнера перед ремонтом туннеля.
- Статусы, Easy/Advanced, CLI capacity, установка и обновление для нового режима.

# 0.3.0

- До 99 независимых экземпляров и 1–32 туннеля в каждом.
- Общий обзор, группы шаблонов, Easy/Advanced, настройки портов и частного bind.
- Шаблоны Gemini/YouTube с предварительной проверкой и отчётом частичного отказа.
- YouTube Mode: наблюдаемый Google RU, отдельно от Gemini.
- HTTP proxy / CONNECT через проверенные WARP backend.
- Выгрузка Xray routing для двух режимов и сохранённого подключения.
- Установка недостающих зависимостей, учёт принадлежности и защищённое удаление.
- Автоматическая установка браузерного TLS-профиля и Compose fallback с SHA-256.
- Обновление одного/всех экземпляров из каталога, ZIP или HTTPS с известным SHA-256.
- Сохранение запуска, автозапуска, портов, регистраций и ограничений при обновлении.
- Опциональный least_connections, принудительная полная проверка и стартовый grace.
- Матрица сопоставления с исходным Auto-Pin в FEATURE_PARITY_RU.md.

# 0.2.0

- Русское консольное меню и CLI для статуса, проверок, скорости, ротации,
  настроек, журналов, start/stop/restart и Xray JSON.
- Подтверждение одинаковых отказов перед сменой регистрации; подозрительный
  туннель сразу исключается из выбора новых соединений.
- Сохранение истории ремонтов, отклонённых IP и пауз через перезапуск.
- Быстрая проверка нового выхода после ротации независимо от паузы до следующей.
- Измерение скорости с настраиваемым порогом и последовательными пробами.
  Ошибка тестового узла не отключает подтверждённый Google/Gemini-туннель.
- Блокировка и таймаут реальной ротации внутри контейнера.
- Обновление с предварительной сборкой, резервным копированием исходников/настроек
  и восстановлением при ошибке; регистрационные тома сохраняются.
- Удаление с сохранением томов по умолчанию; удаление профилей включается явно.
- 27 автоматических тестов и отдельная ручная транспортная проверка.
